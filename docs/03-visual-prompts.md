# INORI — готовые промпты (целыми блоками)

Каждый блок — законченный промпт: сюжет + фирменный стиль + запреты. Копируй блок целиком в генератор.

- **Формат** — выставляй в настройках генератора (или допиши в конец, например `--ar 21:9` для Midjourney).
- **Имя файла** — сохраняй так, клади в `assets/images/<страница>/`.
- Палитра: индиго `#4352F0`, лавандово-голубой `#7C8AF6`, тёмно-синий `#070A1F`, светлый `#F5F6FB`.
- Начни с Home: hero + 4 шага How it works — проверим стиль, потом остальное.
